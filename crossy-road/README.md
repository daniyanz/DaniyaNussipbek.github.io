This game is meant to mimic the classic Crossy Roads game. The chicken is supposed to travel upwards, trying to avoid getting drowned 
or hit by a car. 

It differs from the original game due to differences in graphics. 
The graphics in Crossy Roads have an isometric view to all shapes. 
Kiro struggled making those graphics, failing to generate good enough graphics code for the game. 
A lot of time was put into trying to achieve those graphics, but the game mechanics would break when adding those graphics 
or the orientation of the chicken was incorrect. So after honest attempts to get to the isometric view, I returned to the 2D view of the game. 

I used the Auto mode to save credits. This mode selects the model depending on the task. 

If I had more time, I would definitely add sound effects to make the game more pleasant.
